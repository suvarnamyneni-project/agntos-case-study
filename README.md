# agntOS — UX case study

Portfolio case study and clickable screen walkthrough by Suvarna Myneni, for agntOS, eXp Realty’s AI-native transaction and operations platform.

- Case study: `index.html`
- Interactive walkthrough: `walkthrough.html` (79 product screens, `#01` through `#79`)

The walkthrough matches the My eXp Plus viewer: a sidebar grouped by section, search, previous and next, a back stack, and keyboard shortcuts (`←` `→` previous/next, `H` hotspots, `Backspace` back). Hotspots are on the screens where a control could be placed reliably. The other screens step with the arrows.

Screens use desktop browser frames. Research diagrams, flows, and reconstructed early wireframes are on the case study page. All names, addresses, and figures in the product screens are fictional demo data. The work is designed and prototyped. Outcome metrics are not claimed.
