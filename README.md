# agntOS — UX case study

Portfolio case study and clickable screen walkthrough by Suvarna Myneni, for agntOS, an AI-native transaction platform.

- Case study: `index.html`
- Interactive walkthrough: `walkthrough.html`

The walkthrough is a sidebar viewer: sections, search, previous and next, a back stack, and keyboard shortcuts (`←` `→` previous/next, `H` hotspots, `Backspace` back). Hotspots are on the screens where a control could be placed reliably. The other screens step with the arrows.

Screens use desktop browser frames. Research diagrams on the case study page are drawn in the page itself. Names, addresses, and figures in the product screens are fictional demo data. The work is designed and prototyped. Outcome metrics are not claimed.
